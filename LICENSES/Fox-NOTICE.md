# Fox model and animation attribution

The bundled `assets/library/fox.glb` is the unchanged Fox asset from the Khronos
glTF Sample Assets repository. It supplies the animal library's Walk, Run and
Survey (Look around) animations.

- Model: **PixelMannen**, 2014 — **CC0 1.0 Universal**.
- Rigging and animation: **tomkranis**, 2014 — **CC BY 4.0**.
- Conversion to glTF: **@AsoboStudio and @scurest**, 2017 — **CC BY 4.0**.
- Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox
- Per-asset legal metadata: https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/Fox/metadata.json
- Exact GLB: https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/Fox/glTF-Binary/Fox.glb
- CC0 legal text: https://creativecommons.org/publicdomain/zero/1.0/legalcode
- CC BY 4.0 legal text: https://creativecommons.org/licenses/by/4.0/legalcode

The original metadata is retained beside the model as `fox.metadata.json`.
An identical `fox.glb.bytes` packaging copy preserves the original GLB data for
runtime import after Godot resource remapping.
The asset data have not been changed. Previs applies its own runtime playback,
timing and blending to the original animations. The imported model uses centimetre
coordinates; Previs displays it with a 0.01 scene-object scale.

GLB SHA-256: `D97044E701822BAC5A62696459B27D7B375AADA5DE8574ED4362EDBBA94771F7`.

These asset licences are separate from the Previs application licence. Retain
this credit and the licence links when redistributing the bundled asset.
