# Live AI: forward walking and a smooth camera orbit

Open ai-smooth-orbit.goprevis, or use Open smooth orbit demo.cmd beside GoPrevis.exe. Press Space in camera view.

The saved shot was created through a real GPT-6.1 Sol / High request, rehearsed in the real program, sent to the model as rendered filmstrips, visually assessed and committed. The person uses a timed path with tangent orientation and in-place walking; the camera uses a full analytic 360-degree Orbit, with no sampled position/rotation keys. All parameters and animation remain editable. Select the camera and expand Camera movement to edit radius, sweep, height and duration.

The neighbouring .assets folder contains its motion source. No API request is needed to open, play or edit this example. The MP4 preview shows the active camera. Validation includes actual side-view gait filmstrips and an intentionally reversed counterexample.
